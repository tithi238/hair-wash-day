# Hair Wash Day

A polished mobile-first React/Vite hair-wash tracker.

## Features
- Interactive monthly calendar
- Wash logging/editing/deleting
- Product, oiling, condition and notes
- Optional progress photo
- Planned wash days
- Wash frequency and in-app reminder settings
- Weekly routine planner
- Calculated statistics
- JSON export and clear-data controls
- localStorage persistence
- Responsive mobile bottom navigation + desktop sidebar

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build
```bash
npm run build
npm run preview
```

No backend or login is required.
